# ☕ BREW & BLOOM – Luxury Café Website

Welcome to **BREW & BLOOM**, a modern and elegant café website designed to provide visitors with a beautiful online café experience.

The website showcases the café's menu, gallery, atmosphere and table reservation interface using HTML, CSS and JavaScript.

## 🌟 Project Overview

BREW & BLOOM is a responsive, multi-section café website created as a front-end web development project.

It combines an elegant design with interactive features to make browsing simple and enjoyable.

## ✨ Features

- **Home Page:** Introduction to the café and its experience.
- **Menu Page:** Coffee, desserts and their prices.
- **Gallery Page:** Café images with an interactive image lightbox.
- **Contact Page:** Contact information and reservation form.
- **Dark Mode:** Switch between light and dark themes.
- **Responsive Design:** Works on desktop, tablet and mobile screens.
- **Mobile Navigation:** Easy-to-use navigation menu.
- **Booking Form:** Form validation and demo confirmation message.
- **Google Maps:** Embedded map location.
- **Back to Top:** Quickly return to the top of the page.

## 🚀 How to Run the Project

1. Download or clone the project repository.
2. Open the project folder in Visual Studio Code.
3. Make sure all three website files are in the same folder.
4. Open `index.html`.
5. Run the website using the Live Server extension.
6. Explore the Home, Menu, Gallery and Contact sections.
